# 听记验收清单

1. `/api/health` 返回 `status: ok`，首页标题为“听记 - 实时录音笔记”。
2. 新建空白记录时为“准备就绪”，不得自动申请或开启麦克风。
3. 会议演示结束后应有 5 段转写、1 条决策、2 条行动项、1 条待确认问题。
4. 点击“AI 深度整理”后，成功时摘要来源显示 `OPENCLAW`；失败时已有本地摘要保持不变。
5. 摘要时间戳可定位转写；导出菜单包含 Markdown、TXT、SRT、JSON，真实录音结束后还包含 WebM。
6. 刷新页面后转写和摘要恢复；异常退出的 recording 状态恢复为 paused。
7. 1440px 与 390px 视口均无横向溢出，标题、操作按钮和总结区可访问。
8. 项目 `npm test`、`npm run lint`、`npm run build` 全部通过。
